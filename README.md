# embeddings-vs-keyword-search

Embedding, BM25 and hybrid retrieval, tested in two independent studies. Each folder has its own README, code, raw results and verdict.

- [`original-run`](original-run/) Embeddings / semantic search vs BM25 keyword search on SciFact — **INCONCLUSIVE**
- [`hybrid-search-fresh`](hybrid-search-fresh/) Does pilot-tuned hybrid search transfer to fresh datasets? — **DISPROVEN**

Large artifacts excluded from git are attached to release [`v1-data`](https://github.com/nankris/embeddings-vs-keyword-search/releases/tag/v1-data); see [RELEASE_ASSETS.md](RELEASE_ASSETS.md).
